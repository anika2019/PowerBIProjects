# PowerBIProjects
basic to advanced exercises  to learn POWER-BI
all the supporting files and complete project can be find on Link : https://drive.google.com/file/d/1X3anCdqchO7-HXqnrj48p9xB62eXgFet/view?usp=drive_link

Key Learning from this project

1. Use of different charts (Bar, Donuts, Matrix, Table, Pie etc) based on business case.
2. Use of different slicers (page level, visual level etc.) to filter data.
3. Use of Dynamic slicers.
4. Dynamic data display based on particular selection.
5. Use of Statis Table.
6. Use of dynamic Table.
7. Use of Button for navigation across different pages.
8. Use of tool tips.

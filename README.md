# PowerBIProjects
basic to advanced level exercises  to learn POWER-BI functionalities.
all the supporting files and complete project can be found on this Link too: https://drive.google.com/file/d/1X3anCdqchO7-HXqnrj48p9xB62eXgFet/view?usp=drive_link

kindly go through the sub-branches project-1, project-2 and project-3 for detailed working projects

Key Learning from this project

1. Use of different charts (Bar, Donuts, Matrix, Table, Pie etc) based on business case.
2. Use of different slicers (page level, visual level etc.) to filter data.
3. Use of Dynamic slicers.
4. Dynamic data display based on particular selection.
5. Use of Statis Table.
6. Use of dynamic Table.
7. Use of Button for navigation across different pages.
8. Use of tool tips.
